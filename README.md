# ApexTyers1
apexTyre.com is a responsive B2B/B2C tyre marketplace built with Tailwind CSS (Neon/Glassmorphism UI). Features instant cart/checkout, automated GST invoicing via EmailJS, interactive dark mode, and an Instagram community hub [@apex.tyreworx]. Developed by Lead Dev Swapnil Narwade &amp; Krishna Takalkar (KT SOLUTION).
